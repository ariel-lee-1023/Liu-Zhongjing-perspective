# 參考模組與編輯專題的更正

使用者明確要求 `references/` 只收錄對作者的歸納總結，並將前次兩篇專題移到別的資料夾。本輪以 `dfc3596` 為基線落實此界線。

## 改正內容

前次兩篇混合了作者觀點、編者設計的讀題步驟、教學說明和應用建議。將它們稱作作者推理的重構，並不能使後三者成為作者的論述。兩篇已移至 [編輯筆記](../editorial-notes/books-2026-10-31/README.md)，只修正相對連結，保留原稿以便辨認問題，不再供人格載入。

[C02](../../references/clusters/c02-premodern-order.md) 的乙組改為直接歸納《經與史》《從華夏到中國》的作者觀點：經史關係、周禮與宗法、游士啟蒙、儒家各階段及其兩項恆常承諾、郡縣、賓客、門閥軍戶、科舉、藩鎮、稅役鹽鈔、法統繼承和世界秩序。原有問答與講座案例保留；新增內容不包含編者的現代提問流程或應用處方。

原書中的立場和因果予以歸納，例如孔孟荀三階段、經義與律例的層級、儒家政治失敗與社會重建成功、寶鈔體制的階級後果；沒有把作者改寫成一般制度分析教程。C02 原有的寄主複用提示改為對其論述方式的描述，裝配測試等編輯經過移出執行內容。

SKILL 和 README 的兩專題入口已移除，C05 新檔名保留。核心的技術歸屬說明補上使用者要求的界線；未改人格主體、voice、frameworks 及其他主簇。README 開場保留，使用者既有 AGENTS.md 修改保留且不提交。

## 來源與篇幅

重新從原 EPUB 核對兩書指紋、28 個抽取項目及前次33組來源區間；以這些原文作為歸納依據，不把編輯專題當來源。章節與來源代碼對應見 [correction.json](correction.json)，具體原文位置沿用[既有來源記錄](../books-2026-10-31/source-review.json)。閱讀範圍仍是前次選段，沒有增加全書覆蓋宣稱，亦未重新核驗整個人格或全部舊引述。

本輪把作者觀點合回一個既有簇，C02篇幅增加；原有 C02 加兩篇專題的合計載入量則下降。實際字元與估算 tokens 記錄於 correction.json。這項取捨遵循使用者要求的內容邊界，篇幅只作容量記錄，不作蒸餾充分的證據。
