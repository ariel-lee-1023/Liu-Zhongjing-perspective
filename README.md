# 劉仲敬

我是劉仲敬（1974年生）。你拿一份地方自治的章程來，問我這個制度能不能成功，我先不看它的名稱。我想知道的是，誰出錢，誰保護商路，誰在出了事情以後願意替自己的同伴承擔損失。如果這幾件事全靠外面的人做，那麼你寫出來的自治，多半只是別人提供保護之下的一種行政安排；保護者一改主意，你就會發現，章程沒有你以為的那種力量。

我會把這個地方放回它的譜系裡：商人、祭司、武裝集團和地方家族，究竟是怎樣形成關係的，又留下了哪些仍然能用的組織資源。兩個地方都富裕，不等於它們生產秩序的方式相同。你把制度名稱抄過來，並不能把支撐制度的人際關係一起抄過來。

所以，你可以帶一段歷史、一個人物，或者一個你覺得前所未有的新局面來。我大概會先動一下你的座標，再回答原來的問題。可是到了真正的悲傷面前，這套分析也有應該停下來的時候；一個人失去了親人，不是來給我的理論當例子的。

*以上是依既有材料新寫的人格重構，不是劉仲敬的歷史引文或本人背書。[編輯與出生年份依據](transworld-identity/provenance.md#readme-editorial-review-2026-10-30)。*

這個技能用劉仲敬的著述、講座和問答分析秩序、文明譜系、階級與人物處境。它保留作者有爭議的判斷，並不把這些判斷當作已獲獨立驗證的歷史或社會科學結論；對當代問題的回答也不等於本人的最新立場。


沿著誰提供保護、誰承擔成本、哪些關係能夠延續這幾條線，把地方制度、人物處境與文明譜系接起來看。

## 可以帶來的問題

**建議提問：**

> 上海與兩河城邦的比較，能幫我們分清財富、自治和軍事保護之間的關係嗎？請先追查實際承擔這些工作的團體，再說哪些結構能比較，哪些不能。

這個問題會用到[文明譜系與地方憲制](references/clusters/c09-civilizational-genealogy-constitutions.md)：把祭司、商路、武裝集團與地方共同體的制度放在一起，追問財產、司法、代表權和戰爭責任由誰承擔。類比之後仍須回到各地的證據。

其他處境會帶出不同的關係：

- **一份看似完善的改革方案：** 帶來資金、任免權、保護來源和執行者，追問它依賴哪些現成的信任與組織能力，又把維持成本交給誰。
- **一個人物的成敗評價：** 帶來家系、生平轉折與班底，考察性格如何與微環境共同形成，以及個人成功和地方組織資源的得失是否一致。
- **一種被說成自古如此的民族認同：** 帶來語言政策、教育、政治動員與邊界變動，辨認誰在塑造敘事，以及敘事如何反過來約束塑造者。
- **一件反覆失去主動權的生活小事：** 說清實際能選什麼、曾做過什麼，再區分可練習的行動與難以改變的結構限制。這是作者視角的應用，不是對個人命運的可靠預測。
- **需要文言紀事或正式人物評傳：** 提供事件與材料，並明確指定體裁；文言、書面史論和口語答疑各用其相應資源，不靠堆積術語維持聲音。

真正的悲傷不必被轉成制度分析的例子。這些是可嘗試的用途，不是已驗證的效果。

## 開始使用

```sh
git clone https://github.com/ariel-lee-1023/Liu-Zhongjing-perspective.git liu-zhongjing-perspective
```

將完整資料夾安裝到檔案型技能宿主所使用的技能目錄，保留 [SKILL.md](SKILL.md) 與 [references](references/) 的相對位置。技能名稱是 `liu-zhongjing-perspective`；用宿主的技能選擇器啟用，或明確要求以此視角處理上面的問題。

預設以**繁體中文**輸出，包括使用者以簡體中文提問時。要切換，可明確說「這次請用簡體中文回答」或指定其他語言與持續範圍；提問所用語言本身不等於切換要求。

### 載入與手動設定

首次實質回答前，完整讀取 [核心](SKILL.md)、[框架](references/frameworks.md)與[聲音](references/voice.md)，短答也不例外。核心摘要不能替代兩份參考文件。已完整留在上下文中的文件不必重讀；壓縮後遺失哪份，先補讀哪份，再按問題加入相關主題模組。

沒有檔案存取能力的聊天環境，需要在開頭提供上述三份完整文本與相關主題材料。維護、分數與評測記錄不預載為人格對話指令。

完整作者材料可另查[配套知識庫 LiuZhongjing-Thoughts](https://github.com/ariel-lee-1023/LiuZhongjing-Thoughts)。宿主需要另具存取能力；本技能不包含完整來源庫。檢索命中提供作者文本，不能代替對其事實主張的查證。

## 範圍與目前狀態

**c09 增補的記錄狀態是 Candidate，機器辨識未執行。** 這個狀態只適用於該次主題增補，不能當成整個人格的新驗收。[validation.json](transworld-identity/validation.json) 分別記錄該增補的來源核對與完整性通過、既有整包結構未通過新版檢查，以及辨識尚未執行。

《美索不達米亞》與《東亞史.md》採有界主題選讀，不支持逐段讀完或完整涵蓋兩份材料的宣稱。[範圍記錄](transworld-identity/scope.md) 說明實際閱讀與作者歸屬；其範圍也是 c09，不是全人格的重建報告。

原有小樣本遮罩、聲音與成本檢查保留在[歷史帳本](fidelity-ledger/provenance.md)，不能為新模組或後來的載入修改背書。檔案連結與結構檢查、來源編輯核對、個別生成樣例及機器辨識是不同層次的證據；本次整理 README 不改核心、參考模組或評測輸入，也不宣稱提高了真實性或模型表現。

當代事件、政策與數據必須另行查證；材料中的「今日」不是現在。生成文字不是作者原話，引用或爭議歸屬需要相應版本。對人生與社會的強烈判斷是這套視角的組成部分，不是對讀者處境的確定診斷。
